**Root-Core-Node is live — local testing opens a new frontier**

RootMC just took a step that looks a lot like how **blockchains** and **BitTorrent** grew up: the network is no longer only “servers in the cloud.” Developers can run a **Node** — a first-class peer on the RootMC Network — and prove features on a real Paper world before anything touches Shockbyte.

### What is the Developer Node?
**Root-Core-Node** is the operator console for that peer. It sits on your workstation and wires together:
• Local edge (API preference: RootMC Network vs Cloudflare fallback)
• Local MySQL replicas (`rootmc_claims` / `rootmc_towny`) + `rootmc_dev` for safe experiments
• phpMyAdmin, Discord login, and per-server health tabs
• **NEW: Local Testing** — start/stop/boot/sync the Desktop Paper test server, see bind port, playit address, and Times web in one place

Your **ROOTMC DEV** world runs on Desktop SSD (`RootMC test server`), tunnels via playit, and talks to local MySQL — not production Claims/Towny secrets. Workspace paths still resolve through a junction so scripts stay sane.

### The analogy (why this matters)
**BitTorrent:** one seeder is fragile; many peers make the swarm resilient. A Node is a **seed of truth for development** — you download/sync the data you need, run the stack locally, and push only what is ready.

**Blockchain:** not “crypto,” but **distributed verification**. Mainnet (Shockbyte Claims + Towny) stays the canonical ledger of player economy and towns. A Node is a **devnet / side chain** — full stack, real plugins, isolated schema — where you validate migrations, boot timing, and gameplay without risking live Gold or Towny banks.

Cloudflare remains the public edge when needed; the Node lets us prefer a **RootMC Network path** when the local peer is healthy — like choosing a fast nearby peer over a distant tracker.

### Why Local Testing is the unlock
Before: jar → FileZilla → restart → hope.

### Bottom line
RootMC is growing from “two game hosts + an API” into a **node network**: live hosts for players, developer Nodes for builders. Torrents taught us peers beat single points of failure. Ledgers taught us isolate testnets from mainnet. We’re doing both — and Local Testing is the door.
