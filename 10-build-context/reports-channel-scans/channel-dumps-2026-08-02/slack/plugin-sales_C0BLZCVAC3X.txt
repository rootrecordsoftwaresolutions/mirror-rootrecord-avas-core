*RootMC — Plugin sales research (Jul 2026)*
Channel for planning public paid plugins, web pages, and marketplace listings.

 *1) Tier-1 paid marketplaces (primary sell targets)*

*SpigotMC Resources (premium)*
• <https://www.spigotmc.org/resources/|spigotmc.org/resources>
• Largest Java plugin audience; still the default place server owners look
• Platform fee: *0%* — you keep 100% of sale; payments are buyer:left_right_arrow:seller (usually PayPal)
• Price cap: *$0.99–$19.99* USD
• Seller gate (must meet before premium upload):
– Account ≥ 8 weeks old
– 80 forum posts + 20 positive ratings
– *3 free resources* published
– 2FA enabled
• Approval often ~1 week; “low effort” / common genres can be rejected
• *DRM / license keys that block the jar from running are prohibited* — plugin must work from downloaded file; obfuscation allowed with caveats
• Guidelines: <https://www.spigotmc.org/threads/premium-resource-guidelines.31667/|spigotmc.org/threads/premium-resource-guidelines.31667>
• Best for: max discoverability + free funnel into paid products
*BuiltByBit (ex MC-Market)*
• <https://builtbybit.com/resources/categories/minecraft-plugins.1/|builtbybit.com/resources/categories/minecraft-plugins.1>
• Paid plugins browse: <https://builtbybit.com/resources/minecraft/plugins/paid/|builtbybit.com/resources/minecraft/plugins/paid>
• Creators: <https://builtbybit.com/resources/creators|builtbybit.com/resources/creators>
• Platform fee: *~9.9%* + payment gateway fees; payouts via *Tebex wallet*
• No hard Spigot-style $19.99 ceiling (higher prices OK; mins often ~$1.99–$5.99 by category)
• Also sells maps, configs, models, *custom plugin commissions*
• Pro seller features / referrals optional
• Best for: premium buyers, higher price points, services + products
*Polymart*
• <https://polymart.org/|polymart.org> — plugins: <https://polymart.org/products/category/2/plugins|polymart.org/products/category/2/plugins>
• Modern marketplace with *built-in checkout*, buyer management, license delivery
• Takes a *% fee per sale* (check current schedule on-site when listing)
• Developer API (purchase verify / updates): <https://www.polymart.org/wiki/api|polymart.org/wiki/api>
• Supports Spigot/Paper/Velocity/Bungee/etc. tags *Sent using* Cursor

 *2) Emerging / niche paid marketplaces*

*Hye* — <https://hye.gg/|hye.gg>
• “Try plugin 30 min on temp server before buy”
• Claims *~5% creator fee*; Stripe; license signing; plugins/mods/builds
• Worth evaluating for modern buyer conversion
*PulsePlugin* — <https://pulseplugin.net/|pulseplugin.net>
• Per-buyer encrypted builds / anti-leak focus
• Claims *70% to creator* (30% platform)
• Seller apply flow on site — evaluate maturity before relying on it
*TrustMyServer marketplace* — <https://trustmyserver.com/marketplace|trustmyserver.com/marketplace>
• Multi-game (Minecraft included); Stripe Connect
• Claims *~10% platform / 90% creator*; instant payouts
*GameServersHub (GSH)* — <https://gameservershub.com/become-a-creator|gameservershub.com/become-a-creator>
• Plugins/maps/assets; claims *10% fee*, instant payouts
• Broader “game server” audience, not MC-only
*AdvancedPlugins* — <https://advancedplugins.net/|advancedplugins.net>
• Studio/storefront model (own products + shop), not a open open-to-all marketplace like Spigot
• Useful as a *reference for premium presentation / own-brand store*, not as a listing portal
*Craftaro / Songoda (legacy note)*
• Songoda content moved into Craftaro historically; treat as *verify-before-use* — do not assume active open seller onboarding without checking <http://craftaro.com|craftaro.com> today

 *6) Practical RootMC go-to-market plan*

*Phase A — Inventory*
• List Gen1 plugins eligible for public paid release (unique value, supportable, EULA-safe)
• Decide free “lite” vs premium full for each
*Phase B — Accounts &amp; gates*

*Phase C — Packaging*
• Professional resource pages: feature list, screenshots, video, docs URL, support Discord
• Version matrix (Paper versions), dependencies, changelog
• Pricing strategy: Spigot ≤ $19.99; BBB/Polymart can carry higher “complete suite” SKUs if needed
• Licensing: Spigot-safe (no hard online lock); Polymart/BBB can use their license APIs
*Phase D — Web*
• New <http://rootmc.net|rootmc.net> pages: plugin catalog, per-plugin product page, purchase links, docs
• Optional: aggregate “download portal” that deep-links to marketplace files (don’t violate reupload rules)
*Phase E — Multi-list*
• Same plugin on Spigot + Polymart + BuiltByBit maximizes reach (audiences don’t fully overlap)
• Centralize licenses/support so buyers aren’t orphaned across sites
